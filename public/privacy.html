Privacidade

A ÁguaDaPraia usa Cloudflare Web Analytics para obter estatísticas agregadas sobre páginas visitadas, país aproximado, tipo de dispositivo, navegador e desempenho do site. Estas estatísticas não usam cookies, identificação de utilizadores, publicidade, fingerprinting ou gravação de sessões.

As preferências de idioma, tema, unidade de vento, indicador e região são guardadas apenas no navegador. A opção «Perto de mim» pede autorização para usar a localização neste dispositivo; a aplicação não guarda as coordenadas.

Os dados meteorológicos e oceanográficos têm como fonte o IPMA.pt. O site está alojado no GitHub Pages, que regista endereços IP por motivos de segurança. Consulte a política de privacidade do GitHub.

Privacy

ÁguaDaPraia uses Cloudflare Web Analytics for aggregate statistics on pages visited, approximate country, device type, browser and site performance. These statistics do not use cookies, user identification, advertising, fingerprinting or session recording.

Language, theme, wind unit, metric and region preferences are stored only in your browser. “Near me” asks permission to use your location on this device; the application does not store the coordinates.

Meteorological and oceanographic data comes from IPMA.pt. The site is hosted on GitHub Pages, which logs IP addresses for security purposes. See the GitHub privacy statement.
