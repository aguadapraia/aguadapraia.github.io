Privacidade

A ÁguaDaPraia usa Cloudflare Web Analytics para estatísticas agregadas de utilização e desempenho. Estas estatísticas não usam cookies, identificação de utilizadores, publicidade, fingerprinting ou gravação de sessões.

As preferências de idioma, tema, unidade de vento, indicador e região são guardadas apenas no navegador. A opção «Perto de mim» pede autorização para usar a localização neste dispositivo; as coordenadas não são guardadas nem enviadas pela aplicação.

As estatísticas podem incluir páginas visitadas, origem da visita, país aproximado, tipo de dispositivo, navegador e métricas de desempenho. Comparamos a utilização do Mapa, Tabela e Histórico ao longo do tempo; não registamos praias selecionadas nem termos de pesquisa nas estatísticas. Consulte a informação da Cloudflare.

Os dados meteorológicos e oceanográficos têm origem no IPMA.pt.

O site é alojado no GitHub Pages, que regista endereços IP por motivos de segurança. As previsões são fornecidas pela nossa API no Microsoft Azure. Estes registos operacionais não são usados pela aplicação para publicidade ou perfis de visitantes. Privacidade do GitHub.

Privacy

ÁguaDaPraia uses Cloudflare Web Analytics for aggregate usage and performance statistics. These statistics do not use cookies, user identification, advertising, fingerprinting, or session recording.

Language, theme, wind unit, metric and region preferences are stored only in your browser. “Near me” asks permission to use your location on this device; the application does not store or send the coordinates.

Statistics may include visited pages, referrer, approximate country, device type, browser, and performance metrics. We compare Map, Table and History usage over time; selected beaches and search terms are not recorded in analytics. See Cloudflare information.

Meteorological and oceanographic data originates from IPMA.pt.

GitHub Pages hosts this site and logs IP addresses for security purposes. Forecasts are served by our API in Microsoft Azure. The application does not use these operational logs for advertising or visitor profiles. GitHub privacy statement.
